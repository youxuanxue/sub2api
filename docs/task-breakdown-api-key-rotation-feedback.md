# API Key 轮换与工单反馈任务拆解

## API Key 轮换

- 在既有 API Key 记录上生成并写入新凭证值。
- 保留原 ID、名称和全部策略字段，旧凭证立即失效。
- 增加用户端操作按钮、确认提示、成功/失败提示和中英文文案。
- 保持禁用、删除路径不变。

## 工单反馈

- 增加工单表、用户创建/查询接口和管理员列表/状态更新接口。
- 增加用户提交与查看页面、管理员处理页面。
- 创建或状态变更后向已配置飞书群发送脱敏通知。
- 飞书通知失败不影响系统内工单数据。

## 验收

- API Key 轮换只改变 key 值；越权和写入失败均不产生错误更新。
- 用户只能看到自己的工单，管理员可更新状态。
- 通知内容不包含凭证明文，且未配置或发送失败时工单仍成功落库。
